# Twin Cities Animal Rescue

Static site for Twin Cities Animal Rescue. The pages are Home, Adopt, Foster & Volunteer, About Us, and Get Involved.

On Adopt, Foster & Volunteer, you can pick volunteer roles. The browser remembers those choices. Get Involved has an interest form that checks the fields before it saves your name and email.

Clone the repo and open `index.html` in a browser. A static file server works too.
