# Twin Cities Animal Rescue (Touchstone Task 2)

Multi-page nonprofit-style website for Twin Cities Animal Rescue, built as a web development touchstone assignment.

## Description
Static site with Home, Services (adopt/foster/volunteer), About, and Get Involved pages. Includes responsive images, video/audio embeds, a volunteer role tracker, and contact-form validation using browser localStorage.

## Technologies
- HTML5, CSS3, JavaScript (vanilla)

## Setup
Clone the repo and open `index.html` in a browser (or use any static file server).

## Usage
- Browse pages via the nav.
- On Services, select volunteer roles (saved in localStorage).
- On Contact, complete the interest form (client-side validation).

## Status
Completed course touchstone. Learning / portfolio web project.
